# B站动态净览

一个面向 `https://t.bilibili.com/` 的独立原创油猴脚本：按关注分组筛选动态，并提供关键词、内容类型、本地隐藏、本地稍后看和阅读布局调整。项目借鉴了同类脚本的产品思路，代码从头重写，未复制参考脚本的源码。

> [!IMPORTANT]
> 脚本依赖 B 站网页 DOM 和非公开内部接口。B 站改版或调整接口后，分组读取或卡片识别可能暂时失效。

## 主要功能

- 关注分组三态筛选：左键点击分组设为包含（蓝色），右键点击设为排除（红色），支持搜索分组与按账号保存条件。
- 内容类型过滤：视频、图文、转发、直播、番剧影视和其他。未能可靠识别的类型默认保留。
- 关键词屏蔽：每行一个普通文本关键词，可选是否区分大小写；不将输入当作正则表达式。
- 卡片本地操作：UP 主昵称右侧可隐藏单条动态（支持短时撤销和稍后批量恢复），或加入与 B 站官方稍后看相互独立的“本地稍后看”；空间不足时昵称会自动省略。
- 浮动面板：展示已显示、已隐藏和待识别数量，可收起至彩色渐变“漏斗 + 闪光”图标；入口可固定在左下、右下、左上或右上，刷新后保留选择。
- 模块折叠：关注分组、隐藏内容类型、关键词屏蔽、界面与布局可独立收起到只剩标题，多个模块同时收起时面板会平滑重排，并在刷新后恢复上次状态。
- 面板展开：可选择自动、上、下、左、右五种展开方向；指定方向空间不足时会自动避让并保持在视口内。
- 阅读布局：跟随系统/浅色/深色主题，舒适/紧凑密度，原始/加宽信息流，隐藏侧栏的专注模式，以及 `80%`–`150%` 的界面字号缩放。
- 设置导入与导出：便于备份筛选和布局选项；导出文件不包含隐藏记录和本地稍后看。
- 动态页适配：监听无限滚动新增卡片和站内路由变化，分批处理已有卡片，并对加载或识别失败采取“宁可多显示”的容错策略。

## 安装

需要较新版本的 Chrome、Edge 或 Firefox，以及 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。

1. 获取已构建的 `dist/BilibiliTimeline.user.js`。如果仓库中还没有 `dist`，请先按下文命令构建。
2. 在用户脚本管理器中安装该 `.user.js` 文件。如果浏览器没有从本地文件弹出安装页，请在管理器中“新建脚本”，用该文件的完整内容替换默认模板后保存。
3. 如果使用 Chrome/Edge + Tampermonkey 5.3 或更高版本，还需在扩展详情中启用“允许用户脚本”（Chrome 138+），或在扩展管理页开启“开发者模式”；这是 Tampermonkey 在 Chromium 上执行用户脚本所需的额外权限。详见 [Tampermonkey 官方 FAQ Q209](https://www.tampermonkey.net/faq.php?q=Q209)。
4. 打开或刷新 `https://t.bilibili.com/`，点击彩色渐变漏斗图标即可打开面板；可在“界面与布局 → 入口位置”选择四个固定角落之一。

脚本只在 `t.bilibili.com` 上被注入，并只在根路径的动态信息流启用界面和卡片处理。

## 分组操作语义

使用关注分组前需要在 B 站登录。核心语义是“包含取并集、排除优先”。每个分组有三种状态：

| 状态 | 操作 | 效果 |
|---|---|---|
| 中立 | 分组保持灰色 | 该分组不参与筛选 |
| 包含 | 左键点击分组，显示蓝色 | 作者在任一已包含分组中即满足包含条件 |
| 排除 | 右键点击分组，显示红色 | 作者只要在任一已排除分组中就会被过滤 |

对同一状态再次使用相同按键会恢复中立；直接换用另一种按键则会在“包含”和“排除”之间切换。键盘可用 `Enter`/空格切换包含、`Shift+Enter`/`Shift+空格`切换排除。

规则可概括为：

```text
可见 = (未设置包含分组 OR 作者属于任一包含分组)
       AND 作者不属于任一排除分组
```

- 多个“包含”之间取并集，不是交集。
- “排除”优先：如果同一作者同时属于已包含和已排除分组，其动态仍会被隐藏。
- 只设置排除组时，会显示其他所有可识别作者的动态。
- 全部中立时，不执行分组过滤。
- 作者身份、分组缓存或成员列表无法可靠读取时，分组规则对该卡片暂时放行，避免误隐藏。

分组规则不会覆盖其他过滤条件。手动隐藏、分组、类型和关键词中任一条件要求隐藏时，该卡片就不可见。关闭“启用筛选”可立即恢复当前页面中的卡片。

## 其他使用说明

- 点击“关注分组”、“隐藏内容类型”、“关键词屏蔽”或“界面与布局”的标题即可独立收起/展开。收起只隐藏设置控件，不会清空或停用已设定的筛选规则；状态会自动保存。
- 在面板的“入口位置”中可选择左下角、右下角、左上角或右上角，选择会立即保存；刷新页面和改变窗口尺寸后仍会保持在同一角落。顶部位置会避开 B 站固定导航栏，旧版保存的自由坐标会在升级后自动吸附到最近角落。
- 在面板的“展开方向”中可选择自动、上、下、左或右。上/下/左/右表示优先方向，当目标方向空间不足时脚本会自动改用更合适的位置，避免面板超出视口。
- “界面字号”工具条提供 `A−`、滑块、`A+` 和恢复 `100%`，范围为 `80%`–`150%`、每次调整 `10%`，选择会自动保存。字号达到 `130%` 及以上时，设置区域会改用更适合大字阅读的单列布局。
- 分组列表和已读取的分组成员会按账号缓存。分组列表默认在 6 小时内直接使用缓存；“刷新分组”会强制重新同步列表及当前启用条件的分组成员。
- 关键词每行一条，忽略空行和重复项，并按包含关系匹配卡片文本。
- 有稳定动态 ID 的本地隐藏记录最长保留 30 天，最多 2,000 条；无稳定 ID 的卡片只在本次页面会话中隐藏。
- B 站复用或继续“水合”卡片节点时，脚本会用外层动态 ID、作者 UID 与可信内容链接判断是否仍为同一条动态；信号冲突时优先释放隐藏，避免误伤新卡片。
- 如错过撤销提示，可在面板中连续点击两次“恢复本地隐藏”，恢复当前账号在这台设备上隐藏的全部动态。
- 本地稍后看最多保留 500 条，只保存链接、去重标识、标题、作者、页面时间文本和加入时间；链接中的追踪参数不会制造重复条目。
- 找不到可信的当前动态或内容链接时，“本地稍后看”按钮会禁用，避免误把正文提及或转发中的其他链接当成当前动态。
- “恢复默认”需在短时间内点击两次，它会重置筛选和布局设置，但保留本地隐藏记录和本地稍后看。
- 按 `Esc` 可关闭稍后看抽屉或收起面板。

## 隐私与网络请求

本项目的默认构建：

- 没有遥测、埋点、广告或用户画像；
- 没有站外请求，没有 `@require` 或远程第三方依赖；
- 仅使用当前 B 站登录会话对 `api.bilibili.com` 发起只读 `GET` 请求，用于检查登录状态、读取关注分组和分组成员；
- 不会修改关注关系、分组成员或 B 站官方稍后看，也不会复制、导出或上传登录 Cookie；
- 设置、分组缓存、隐藏记录和本地稍后看仅写入 `t.bilibili.com` 的 `localStorage`，其键名以 `__bilibili_timeline_focus_v1__:` 开头；
- 设置导出只会在用户主动点击时生成本地 JSON 文件。

浏览器同步、扩展自身的同步功能及 B 站本身的数据处理不由本脚本控制。

## 兼容性

| 环境 | 支持情况 |
|---|---|
| 较新版 Chrome / Edge + Tampermonkey | 主要目标环境 |
| 较新版 Chrome / Edge + Violentmonkey | 预期兼容 |
| 较新版 Firefox + Violentmonkey / Tampermonkey | 预期兼容，需保持管理器的页面注入权限 |
| Safari、Greasemonkey 或老旧浏览器 | 未测试，不作保证 |

未登录时无法从 B 站读取关注分组，但关键词、类型、布局、本地隐藏，以及具备可信链接的本地稍后看仍可使用。软件兼容性不等于对任意未来 B 站 DOM 或内部接口版本的保证。

## 构建与测试

需要 Node.js 18 或更高版本。

```bash
npm ci
npm run verify
```

`npm run verify` 会依次执行源码和构建脚本语法检查、Node 单元测试、生成 `dist/BilibiliTimeline.user.js`，并再次检查最终单文件脚本的语法。也可分别运行：

```bash
npm run check
npm test
npm run build
```

### 登录端到端测试限制

自动化测试不包含 B 站账号凭据，也不应导入真实用户的 Cookie。因此，单元和 DOM 测试可覆盖筛选语义、数据清理、卡片提取与构建完整性，但无法持续保证真实登录态下的内部接口和实时 DOM。

发布前应在自己的浏览器会话中进行下列手工检查：

1. 登录 B 站后能加载分组，并验证多个包含、只排除、包含与排除冲突三类情形。
2. 向下滚动加载新卡片，再在站内往返切换路由，确认面板和卡片操作不重复。
3. 检查 UP 主昵称右侧的隐藏/本地稍后看操作不遮挡正文，再检查关键词、内容类型、手动隐藏/撤销、本地稍后看、布局，以及四角入口位置、面板展开方向、界面字号和四个模块折叠状态在重载后的持久化。
4. 退出登录或人为模拟接口失败，确认脚本给出状态提示且不误隐藏内容。

## 卸载与清除本地设置

1. 在 Tampermonkey 或 Violentmonkey 中删除“B站动态净览 - 分组筛选与阅读助手”。
2. 刷新 B 站动态页，即可移除脚本添加的面板、工具按钮和布局效果。
3. 如果还要删除保存在浏览器中的所有脚本数据，请在 `https://t.bilibili.com/` 的开发者工具控制台执行：

```js
for (const key of Object.keys(localStorage)) {
  if (key.startsWith("__bilibili_timeline_focus_v1__:")) {
    localStorage.removeItem(key);
  }
}
location.reload();
```

这段代码只删除本脚本前缀下的键，不会主动删除 B 站其他 `localStorage` 数据。也可使用浏览器的“清除网站数据”功能，但那会同时清除该站点的其他本地数据。
